
Analyse school performance (ASP) is a secure system where DfE users, schools, academies, MATs, LAs, Dioceses, Ofsted and governors can access detailed performance data to help support school improvement.

The service is designed to help support accountability policy and helps schools improve by providing accurate attainment data.

**Problem statement**

The next data cycle for Analyse School Performance (ASP) is about to begin, however ASP cannot be run by Operations in its current set up. The service is “clunky” and requires engineering resource to maintain it, it is not GDS compliant and is unlikely to pass accessibility standards in its current form.

**Vision**
The first option for schools, academies, MATs, LAs, Dioceses, Ofsted, governors and DfE users for intuitive, easy to use, personalised analysis of trusted current and historical data - enabling them to identify areas that demonstrate success and opportunity for improvement without additional platforms.

**Objectives**
- Help schools improve by providing accurate, timely attainment data
- Present data in a way that helps Users understand and contextualise 

**How can we achieve our objectives?**
- Create a service that Users will visit and return to
- Make data available as quickly as possible
- Ensure the site is easy and intuitive to navigate
- Continue to deliver high quality data
- Provide tools which allow Users to easily spot areas for improvement, or to share as best practise
- Ensure presented data can be understood by Users with a range of understanding and data experience


**KPIs**

Quantitative Measures
- More schools visiting, and visiting more often (in line with data releases)
- Reduced number of 'bouncebacks' in site navigation
- Maintain or reduce number of reported faults in the data caused by the ASP team

Qualitative Measures
- Increase in User feedback reporting a positive response to the site

**Why do we need a more flexible, responsive ASP?**
- Imminent potential change in departmental priorities
- Demonstrable need for a more flexible product - pandemic, policy changes
- Able to respond to more dynamic competitors to provide value to Users
- Adapt more quickly to User needs
