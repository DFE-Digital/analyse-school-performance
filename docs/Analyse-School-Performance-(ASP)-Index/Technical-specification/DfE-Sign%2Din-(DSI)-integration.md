#[DfE Sign-in](https://services.signin.education.gov.uk/) (DSI) Integration

ASP 2.0 is secured using the DfE sign-in service (DSI). DSI uses the [OAuth 2.0 protocol](https://datatracker.ietf.org/doc/html/rfc6749) with [OpenID Connect](https://openid.net/specs/openid-connect-core-1_0.html) as an identity layer on top of the OAuth 2.0 protocol.

Information about DSI can be found in [this Google Doc](https://docs.google.com/document/d/19E7EiRI_HnwAUjZeBurjPWkKGXCuwkmKAFWcpczHspk/edit#heading=h.ar4xskjgsz9w)
