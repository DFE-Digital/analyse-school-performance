# Accessing the ASP 2.0 environments via DfE Sign-in (DSI)

##ASP 2.0 development and test environments

To access the ASP 2.0 web application in either the dev or test environment you will need an account with the DSI test environment:

https://test-services.signin.education.gov.uk/

To create accounts on the DSI dev and test environments go to the link for each DSI environment below and click on 'Create account', creation of accounts on DSI dev and test does not require approval. You can use your DfE email address.

### ASP 2.0 development service 
https://s192d01-app-dev-01.azurewebsites.net/

### ASP 2.0 development service
https://s192t01-app-test-01.azurewebsites.net/

Once you create accounts on DSI test you will need to ask either _Chris Morriss_ or _Stu Sherwin_ from the ASP team to invite you to the ASP2.0 service.

To request access to the various ASP 2.0 organisations (a type of user) [follow the instructions here](/Analyse-School-Performance-\(ASP\)-Index/New-starter-instructions/Creating-a-DSI-account-and-adding-roles-\(organisations\)-to-your-account).
