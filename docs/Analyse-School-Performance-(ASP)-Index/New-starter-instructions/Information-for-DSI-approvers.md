###Managing user access includes:

- Add services - If a user is associated with a particular organisation but that organisation does not have access to any services then the ASP2.0 service can be added via 'Add services'
- Edit services - Allows an 'Approver' to change or remove a 'Sub-service' from a Service. Sub services are the same a roles.
- Remove services - Remove a service from a users organisation
- Make approver - make the selected users an approver
- Remove from organisation - removed a particular organisation that a user has access to.
