##Creating an account with DfE sign-in

Those who need to access ASP 2.0 will need to [create an account](https://profile.signin.education.gov.uk/register) with the DfE sign-in service

Once approved, you will need to request access to an organisation.

##Requesting access to an organisations
1.	Make sure you sign-out of DSI if not already signed-out
2.	Log into DSI 

![image.png](/docs/.attachments/image-42d76117-a4be-4c2c-9927-398903ddb29d.png)

3.	Then click on ‘request access to an organisation’

![image.png](/docs/.attachments/image-3ce7c28e-c836-4bc0-b0c9-41545fa33acf.png) 

4.	Search for user to add

![image.png](/docs/.attachments/image-894f3dee-93cc-4217-adff-caa7176e1924.png)

5.	Then add user
6.	Then go to ‘Services’
7.	Click on ‘Request access to a service’
8.	Select Org:

![image.png](/docs/.attachments/image-5a8fca28-2f39-4c56-9272-368e246b0eb6.png)

9.	Click continue:

![image.png](/docs/.attachments/image-ee0d712c-0098-4c4f-b76d-ba12b78fe0ba.png)

10.	Then ASP 2.0 and click continue:

![image.png](/docs/.attachments/image-8ccaeca1-2ecc-49a8-85b2-a52bd8f4e209.png) 

11.	Select the Role that you added must be same one which you are currently adding

![image.png](/docs/.attachments/image-5bdeae1d-6487-4c2b-9a88-92d942e6983e.png)

12.	Then click on request service

![image.png](/docs/.attachments/image-5837e99c-da0b-495e-99ae-067fd21b1cc2.png)

13.	Then an approver must approve (should get an email notification):
14.	Then you should see the role appear before going into service, which in our case is ASP 2.0
