
**Project Goals & Objectives**

The ASP 2.0 project is the rewrite of the ASP (Analyse School Performance) application that is currently serving the schools and local authorities that provides the annual and historical performance of their respective school(S) with visual representations and the data drill down.
While the primary Goal of ASP 2.0 is to replicate the BAU functionalities of ASP 1.0 ASIS, it aims at addressing the technical issues such as performance bottlenecks, data standardization by reengineering the application and then to iteratively accommodate the feature updates based on the user research.
